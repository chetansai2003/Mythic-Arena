# Mythic Arena rules — version 1

These are the implementation contract for the first casual 1v1 release. Part 1 defines these rules; Step 3 implements the gameplay engine. R13?R14 online disconnect/readiness scheduling remains Step 4; local practice starts immediately.

| ID  | Rule                                                                                                                                                                                                                                                                                                                                                                          |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R01 | A playable deck contains exactly 30 cards, at most two copies of each definition. All seeded definitions are available to everyone. The initial catalog will contain at least 18 original definitions. Draft decks may be incomplete.                                                                                                                                         |
| R02 | Both heroes begin at 20 maximum/current health, five cards in hand, zero maximum/current energy, and an empty board. The server chooses the first player and shuffles using an injected random seed.                                                                                                                                                                          |
| R03 | A turn is one player's personal turn. At its start, increase that player's maximum energy by one, capped at ten; refill energy, draw one card, and reset their units' attack availability. The first player skips only the first turn's draw. They start turn one with one energy.                                                                                            |
| R04 | Each turn has a 30-second server deadline. End Turn or expiration advances play. Resolve a due deadline before accepting an input received at or after it. Client clocks are display aids only.                                                                                                                                                                               |
| R05 | Each side has five unit slots. Units have cost, attack, maximum/current health, and attack availability. A unit cannot attack on its entry turn and may attack once on each subsequent personal turn. Playing a unit on a full board is invalid.                                                                                                                              |
| R06 | An attacking unit targets an enemy unit or hero. If an enemy Guard unit exists, attacks must target a Guard unit. Spells follow their own target policy, unaffected by Guard.                                                                                                                                                                                                 |
| R07 | Unit combat deals both damage amounts simultaneously. Remove all dead units after the damage batch. Attacking a hero produces no retaliation. Evaluate hero defeat after the complete batch, not halfway through it.                                                                                                                                                          |
| R08 | Shield is a non-stacking boolean that absorbs and consumes itself on the next positive damage instance. Zero damage does not consume it. Heroes and units may receive Shield when an effect permits that target.                                                                                                                                                              |
| R09 | Healing caps at the target's initial maximum health and cannot revive a dead unit. Spells resolve immediately and go to discard. Database content selects finite effect keys; it never supplies executable code.                                                                                                                                                              |
| R10 | The initial spell keys are DAMAGE, HEAL, and SHIELD. DAMAGE has a positive integer amount and ENEMY_CHARACTER target policy. HEAL has a positive integer amount and FRIENDLY_CHARACTER policy. SHIELD has FRIENDLY_CHARACTER policy and no amount. Unit keywords are GUARD and SHIELD, which apply on entry. No other effects are playable until versioned rules define them. |
| R11 | Hands hold at most ten cards. A draw into a full hand discards the drawn card. Each attempt to draw from an empty deck deals fatigue damage of 1, then 2, then 3, increasing separately per player. Fatigue is a damage instance and follows Shield.                                                                                                                          |
| R12 | A hero at zero or lower health loses; simultaneous hero defeat is a draw. Surrender immediately awards the opponent a win. Complete turn 100, resolve any outcome, then declare a draw if still active before turn 101 would start. Terminal matches accept no further game actions.                                                                                          |
| R13 | Disconnect grants 30 seconds to reconnect without pausing turns. At a due disconnect resolution, one expired offline player forfeits; if both players are offline, abort without leaderboard credit. A normal game outcome reached before this deadline remains final. At equal deadlines resolve disconnect before turn expiry.                                              |
| R14 | Both clients must be ready within ten seconds after match reservation. Start immediately when both are ready, otherwise abort without penalty. Intro animation does not consume the first turn. Restore an authoritative snapshot before enabling reconnect controls.                                                                                                         |
| R15 | The release offers casual matchmaking, practice, history, and a wins leaderboard. Aborts/draws/practice award no leaderboard win. Ranked seasons, trading, chat, spectators, and replay playback are deferred.                                                                                                                                                                |
| R16 | Freeze deck contents, card definitions, and rules version on match creation. The server owns all state transitions. Clients see only their hand, public boards, opponent hand count, and deck counts; never opponent hand identities, deck order, or seed.                                                                                                                    |

Card names, artwork, stats, costs, and catalog balancing are Part 2 content decisions. R03, R04, R08, R10, and the exact turn-count boundary in R12 clarify gaps in the original blueprint; they are explicit project decisions.
